## 📌 Overview
FinReach is an end-to-end data analytics portfolio project that demonstrates advanced capabilities in building full-scale data pipelines, analyzing user funnels, segmenting cohorts, and deploying AI-driven action engines.

## 🌟 Key Features
- **Data Generation:** Robust synthetic data creation representing complex user journeys.
- **Funnel & Cohort Analysis:** Advanced SQL architectures tracking user conversion and retention drops.
- **RFM Segmentation & A/B Testing:** Python-based modeling to segment users dynamically and test marketing performance.
- **AI Action Engine:** Leverages generative AI (Gemini) to automate data interpretation and decision-making workflows.
- **Tableau Prep:** SQL transformations to shape data perfectly for visualization tools.

## 🚀 Live Demo
The core functions and API endpoints have been deployed serverless on Vercel.
- **Production URL:** [https://finreach-analytics.vercel.app](https://finreach-analytics.vercel.app)

## 🛠 Tech Stack
- **Languages:** Python 3, SQL
- **Libraries:** Pandas, NumPy, FastAPI, Google GenAI SDK
- **Deployment:** Vercel (Serverless)

## 📁 Repository Structure
- `phase1_data_generation.py` - Synthesizes dataset.
- `phase2_funnel_cohort.sql` - Complex SQL for tracking cohorts.
- `phase3_rfm_ab_testing.py` - Segment analysis and testing.
- `phase4_ai_action_engine.py` - Gemini-powered AI engine.
- `phase5_tableau_prep.sql` - Visualization prep.
- `api/` - Vercel Serverless Function entrypoints.
